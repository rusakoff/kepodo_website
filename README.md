# kepodo website

Отдельный двуязычный лендинг kepodo с выразительной типографикой и рисованной графикой по мотивам two26.studio. Статический HTML, CSS и небольшой JavaScript, без runtime-зависимостей и внешних CDN. Исходники приложения и соседние проекты не меняются.

## Запуск

Нужен Node.js 22+.

```sh
rtk npm run dev
```

- English: http://localhost:4173/en/
- Русский: http://localhost:4173/ru/
- `/` открывает английскую версию; переключатель языка сохраняет текущий раздел.

`dev` пересобирает страницы при изменении `src/` или `public/`. После изменения обновите страницу. Другой порт: `rtk npm run dev -- --port 4180`.

## Сборка и размещение

```sh
rtk npm run build
rtk npm test
rtk npm run preview
```

`dist/` — готовый сайт для любого статического хостинга. Для production задайте `SITE_URL` равным полному адресу сайта, включая путь, если сайт находится в подкаталоге. Сборка настроит пути к ресурсам, добавит абсолютные canonical/alternate/Open Graph URL и `sitemap.xml`. Без него используются пути от корня, а sitemap не генерируется.

Пример для своего домена:

```sh
rtk proxy env SITE_URL=https://your-domain.example npm run build
```

### GitHub Pages

Сайт: https://rusakoff.github.io/kepodo_website/ · [Русская версия](https://rusakoff.github.io/kepodo_website/ru/).

Workflow `.github/workflows/deploy.yml` при каждом push в `main` собирает сайт на Node.js 22, запускает тесты и публикует `dist/` в GitHub Pages. Адрес берётся из настроек Pages автоматически. Публикацию можно также запустить вручную во вкладке Actions. В Settings → Pages источником выбран GitHub Actions.

Для локальной проверки сборки с адресом GitHub Pages:

```sh
rtk proxy env SITE_URL=https://rusakoff.github.io/kepodo_website npm run build
rtk proxy env SITE_URL=https://rusakoff.github.io/kepodo_website npm test
```

`npm run dev` пересобирает локальную версию без пути GitHub Pages; для обычной разработки `SITE_URL` не нужен.

Внешние кнопки ведут в настоящий репозиторий `https://github.com/rusakoff/kepodo` и его инструкцию запуска. На момент создания лендинга публичных релизов не было, поэтому кнопок с несуществующими загрузками нет. После публикации установщиков обновите CTA в `src/page.mjs` и тексты установки в обеих локалях `src/content.mjs`.

## Редактирование

- `src/content.mjs` — весь основной текст на двух языках.
- `src/page.mjs` — структура страниц и метаданные.
- `src/styles.css` — адаптивная вёрстка и дизайн-токены: `#ff5400`, `#f8eee8`, `#f9e2e1`, `#171614`, Unbounded и Manrope.
- `src/main.js` — доступные с клавиатуры вкладки, мобильное меню, увеличение скриншотов и анимации появления.
- `public/assets/` — локальные изображения, логотипы и шрифт.
- `scripts/build.mjs` — генерация статических страниц.
- `scripts/serve.mjs` — локальный сервер с обработкой 404.

Все основные тексты присутствуют в исходном HTML. Изображения ниже первого экрана загружаются лениво, имеют альтернативные описания и размеры. Учитывается `prefers-reduced-motion`; FAQ работает без JavaScript. Для переключения вкладок доступны стрелки, Home и End. Escape закрывает увеличенное изображение и мобильное меню.

## Скриншоты

В `public/assets/screenshots/` — 26 WebP-скриншотов настоящего Electron-интерфейса: чтение, три AI-сценария, заметки, предложения правок, история, подключения, навыки, настройки и обе темы. Документ и ответы подготовлены для демонстрации. Это не проверка реальной подписки или провайдера.

Повторная съёмка требует собранного соседнего `../MarkChat`, его Playwright/Electron-зависимостей и `cwebp`:

```sh
rtk npm run screenshots
```

Существующие снимки пропускаются. Для полной пересъёмки: `rtk npm run screenshots -- --force`. Иной путь к приложению задаётся через `KEPODO_APP_DIR`. Используются изолированные временные профили и локальный тестовый провайдер. Подробнее: `docs/screenshot-provenance.md`.

## Ресурсы

Визуальный референс — [two26.studio](https://two26.studio/): оранжевый, тёплые кремовые и розовые фоны, крупная типографика, чёрные наклейки. Композиция адаптирована под чтение Markdown и работу с AI. Иллюстрация `public/assets/reading-companion.svg` создана специально для kepodo: контурный кальмар с книгой. Карточки вокруг него — декоративные HTML/CSS-элементы; демонстрация настоящего приложения находится в интерактивном обзоре ниже.

Шрифты Manrope и Unbounded загружаются локально. Unbounded взят из [Google Fonts](https://github.com/google/fonts/tree/main/ofl/unbounded); лицензии сохранены в `public/licenses/`. Превью для ссылок используют ту же разметку, палитру и иллюстрацию. Для пересъёмки запустите `node scripts/make-social-pages.mjs` после сборки и снимите `/_social/en.html` и `/_social/ru.html` при размере 1200 × 630. Следующая сборка удалит временные страницы.

Анимации не перехватывают прокрутку: появление секций, лёгкая реакция карточек на указатель и декоративная бегущая строка. При `prefers-reduced-motion: reduce` они отключаются; основной контент виден и без JavaScript. История предыдущего бумажного оформления остаётся в [docs/hero-art-direction.md](docs/hero-art-direction.md).

Значки провайдеров взяты из уже установленного `@lobehub/icons-static-svg` 1.97.0, лицензия MIT находится в `public/licenses/Lobe-Icons-LICENSE`. Логотипы обозначают поддерживаемые подключения, а не партнёрство или одобрение провайдерами.

Сайт не отправляет формы, не собирает адреса и не содержит аналитики.
