# kepodo website

Двуязычный лендинг kepodo в минималистичном стиле shadcn, с визуальным ориентиром на [t3.codes](https://t3.codes/). Тёмная и светлая темы, реальные скриншоты приложения, интерактивный обзор и видео. Статический HTML, CSS и небольшой JavaScript, без runtime-зависимостей и внешних CDN.

## Запуск

Нужен Node.js 22+.

```sh
rtk npm run dev
```

- English: http://localhost:4173/en/
- Русский: http://localhost:4173/ru/
- `/` открывает английскую версию; переключатель языка сохраняет текущий раздел.

`dev` пересобирает страницы при изменении `src/` или `public/`. После изменения обновите страницу. Другой порт: `rtk npm run dev -- --port 4180`.

## Сборка и размещение

```sh
rtk npm run build
rtk npm test
rtk npm run preview
```

`dist/` — готовый сайт для любого статического хостинга. Для production задайте `SITE_URL` равным полному адресу сайта, включая путь, если сайт находится в подкаталоге. Сборка настроит пути к ресурсам, добавит абсолютные canonical/alternate/Open Graph URL и `sitemap.xml`. Без него используются пути от корня, а sitemap не генерируется.

Пример для своего домена:

```sh
rtk proxy env SITE_URL=https://your-domain.example npm run build
```

### GitHub Pages

Сайт: https://rusakoff.github.io/kepodo_website/ · [Русская версия](https://rusakoff.github.io/kepodo_website/ru/).

Workflow `.github/workflows/deploy.yml` при каждом push в `main` собирает сайт на Node.js 22, запускает тесты и публикует `dist/` в GitHub Pages. Адрес берётся из настроек Pages автоматически. Публикацию можно также запустить вручную во вкладке Actions. В Settings → Pages источником выбран GitHub Actions.

Для локальной проверки сборки с адресом GitHub Pages:

```sh
rtk proxy env SITE_URL=https://rusakoff.github.io/kepodo_website npm run build
rtk proxy env SITE_URL=https://rusakoff.github.io/kepodo_website npm test
```

`npm run dev` пересобирает локальную версию без пути GitHub Pages; для обычной разработки `SITE_URL` не нужен.

Ссылка запуска ведёт в репозиторий `https://github.com/rusakoff/kepodo` с явной пометкой о необходимости доступа. Публичный установщик на сайте не обещается. После публикации установщиков обновите CTA в `src/page.mjs` и тексты установки в обеих локалях `src/content.mjs`.

## Редактирование

- `src/content.mjs` — весь основной текст на двух языках.
- `src/page.mjs` — структура страниц и метаданные.
- `src/styles.css` — адаптивная вёрстка и семантические токены в духе shadcn: чёрный фон `#000000`, поверхности `#0c0c0c`, тонкие границы `#222222` и синий акцент `#3266f5`. Светлая тема переопределяет те же токены. Системная типографика, заголовки 76/48/72 px и контейнер 1176 px приближены к t3.codes.
- `src/main.js` — переключение темы и скриншотов, доступные с клавиатуры вкладки, мобильное меню, подсветка текущего раздела, увеличение изображений, копирование команд и переход к нужному демо.
- `public/assets/` — локальные изображения, логотипы и шрифт.
- `scripts/build.mjs` — генерация статических страниц.
- `scripts/serve.mjs` — локальный сервер с обработкой 404.

Все основные тексты присутствуют в исходном HTML. Изображения ниже первого экрана загружаются лениво, имеют альтернативные описания и размеры. Учитывается `prefers-reduced-motion`; FAQ и выбор языка работают без JavaScript. Для переключения вкладок доступны стрелки, Home и End. Escape закрывает увеличенное изображение и мобильное меню.

## Скриншоты

В `public/assets/screenshots/` — WebP-скриншоты настоящего Electron-интерфейса: чтение, три AI-сценария, заметки, предложения правок, история, подключения, навыки и настройки. Снимки с суффиксом `-dark` сняты отдельно в тёмной теме; смена темы сайта переключает изображения и их увеличенные версии. Документ и ответы подготовлены для демонстрации. Это не проверка реальной подписки или провайдера.

Повторная съёмка требует собранного соседнего `../MarkChat`, его Playwright/Electron-зависимостей и `cwebp`:

```sh
rtk npm run screenshots
```

Существующие снимки пропускаются. Для полной пересъёмки: `rtk npm run screenshots -- --force`. Для тёмных изображений сайта: `rtk npm run screenshots -- --dark --force`. Иной путь к приложению задаётся через `KEPODO_APP_DIR`. Используются изолированные временные профили и локальный тестовый провайдер. Код приложения не меняется. Подробнее: `docs/screenshot-provenance.md`.

## Ресурсы

Первый экран повторяет композиционные принципы t3.codes: трёхстрочный белый заголовок, одна синяя кнопка, вторичная текстовая ссылка, наклонённые значки провайдеров. На телефоне четыре значка остаются над заголовком, ещё два — по сторонам вторичного действия. Фирменный логотип берётся из `public/assets/wordmark.png`, иконка вкладки — исходный `public/favicon.png`. Логотип инвертируется в тёмной теме без изменения формы. Первый скриншот помещён в адаптивный CSS-мокап планшета на всю ширину страницы; цельный корпус, камера и боковые кнопки не требуют растрового изображения. Рамка одинаково скруглена со всех сторон. Тень под устройством плавно растворяется в фоне следующего раздела, без горизонтальной границы. В планшете плавно чередуются три скриншота: визуальный разбор, саммари и заметки. Смена каждые пять секунд продолжается при наведении; пауза срабатывает при фокусе на элементах управления, открытом увеличенном изображении и вне экрана. Изображения в планшете не увеличиваются по нажатию. Доступны выбор кадра и кнопка паузы; при `prefers-reduced-motion` автоматическая смена изначально выключена. Без JavaScript остаётся первый кадр. Скриншоты сохраняют пропорции; в остальных разделах они открываются в увеличенном виде. Разделы разделены отступами без декоративных горизонтальных линий, скриншоты чередуются с текстом, финальный призыв расположен без внешней карточки.

Верхняя панель высотой 60 px закреплена при прокрутке: логотип, разделы, язык, тема и переход к обзору. На мобильном экране навигация раскрывается отдельным меню. Тёмная тема включена по умолчанию; выбор сохраняется локально и применяется до первой отрисовки. Кнопки, вкладки, меню, карточки и FAQ используют единый набор нейтральных цветов и небольших скруглений.

Страница проводит посетителя от продукта к первому запуску: крупный первый экран с реальным интерфейсом, три сценария, интерактивные примеры AI-разбора, чтение и заметки, предложения правок, компактный ряд из шести поддерживаемых подключений AI, видеодемонстрация, форматы и ограничения, FAQ и инструкция запуска. Ссылки из сценариев открывают соответствующую вкладку. Скриншоты ниже первого экрана можно увеличить; на телефоне увеличенное изображение можно прокручивать.

Основное действие — «Посмотреть демо». Репозиторий приложения приватный: сайт не обещает публичного скачивания. Отдельный раздел запуска из исходников содержит терминал с командами, требования, ссылку с пометкой о доступе и команды с кнопкой копирования. Подключения описаны по README приложения; модели, лимиты и оплату определяет выбранный провайдер. На сайте нет выдуманных тарифов, отзывов, партнёрств или счётчиков пользователей.

Видеопрезентация доступна в разделе процесса работы: русская на `/ru/`, английская на `/en/`. Ролики `public/assets/videos/kepodo-showreel-{ru,en}.mp4` предоставлены автором (1920 × 1080, около 28 секунд, H.264/AAC). Видео и звук сохранены без перекодирования; MP4 подготовлены для быстрого начала воспроизведения (`faststart`). WebP-постеры взяты из роликов. Загрузка видео начинается по нажатию, доступны стандартные элементы управления, звук, перемотка и полноэкранный режим. Локальный сервер поддерживает `video/mp4` и HTTP Range.

Страница использует системный шрифт, как референс. Manrope, Unbounded и прежние графические ресурсы сохранены в архиве ресурсов, но не загружаются; лицензии остаются в `public/licenses/`. Превью для ссылок используют новую палитру и типографику. Для пересъёмки запустите `rtk proxy node scripts/make-social-pages.mjs` после сборки и снимите `/_social/en.html` и `/_social/ru.html` при размере 1200 × 630. Следующая сборка удалит временные страницы.

Движение ограничено появлением первого экрана, плавной сменой скриншотов в планшете и состояниями элементов. При `prefers-reduced-motion: reduce` анимации и плавная прокрутка отключаются. Основной контент, все три примера, язык, видео и FAQ доступны без JavaScript. Текущий раздел в навигации определяется через IntersectionObserver. История предыдущего оформления остаётся в [docs/hero-art-direction.md](docs/hero-art-direction.md).

Значки провайдеров взяты из уже установленного `@lobehub/icons-static-svg` 1.97.0, лицензия MIT находится в `public/licenses/Lobe-Icons-LICENSE`. Логотипы обозначают поддерживаемые подключения, а не партнёрство или одобрение провайдерами.

Сайт не отправляет формы, не собирает адреса и не содержит аналитики.
