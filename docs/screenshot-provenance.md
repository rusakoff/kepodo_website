# Screenshot provenance

Captured from the real kepodo Electron renderer using its existing isolated test provider. Documents and responses are authored demonstration content, not a live model evaluation. No personal documents or real provider credentials are used. UI markup and CSS are not modified for screenshots.

Run `npm run screenshots` after building the sibling `../MarkChat` app. Requires its Playwright/Electron dependencies and `cwebp`. Screenshots are encoded as WebP at quality 88. The capture script, sample Markdown, and responses are in `scripts/capture-screenshots.mjs`.
